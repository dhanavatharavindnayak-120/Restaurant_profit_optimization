# Restaurant Profit Optimization

## Project Overview
Predictive modeling and what-if analysis for multi-channel restaurant operations.

## Objective
This project predicts monthly restaurant net profit using machine learning and allows users to test different business scenarios.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest
- Streamlit
- Matplotlib

## Features
- Profit prediction
- Restaurant information
- Commission rate analysis
- Delivery cost analysis
- Monthly order analysis
- What-if scenario simulation
- Channel profit analysis

## Machine Learning Model
Random Forest Regression is used to predict total monthly net profit.

## Dashboard
The Streamlit application provides an interactive dashboard for restaurant profit optimization.
